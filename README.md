# Frontend Learning

My front-end learning journey, from plain HTML to CSS and Bootstrap, ending with small standalone websites that put everything together. Lesson files and comments are in Turkish.

## Contents

### `html_dersleri/` — HTML
Core HTML elements and page structure:
- Basic document structure, `div`, links, and image placement/centering
- Ordered and unordered lists
- Tables (with practice examples)
- Forms: inputs, `select`, `textarea` (with practice examples)
- Embedding video and `iframe`

### `css_dersleri/` — CSS
Styling fundamentals, one topic per file:
- Selectors, ID and class, colors, backgrounds
- Text and fonts, width/height, margin, padding, border radius
- `display`, `overflow`, `z-index`
- Link and table styling
- List icons and icon usage (Font Awesome)
- Navigation menus: vertical, horizontal, and dropdown

### `bootstrap_dersleri/` — Bootstrap 4.6
Eleven lessons built on Bootstrap 4.6 and Font Awesome 6:
1. Including Bootstrap
2. Layout and grid system
3. Margin and padding utilities
4. Alerts
5. Text and background utilities
6. Buttons
7. Cards
8. Tables and lists
9. Forms
10. Navbar
11. A sample multi-page site (home, about, contact)

## Mini Projects

| Project | Description |
|---|---|
| **Car website** | A car brand showcase with a navbar, card layout (Mercedes, BMW, Togg), Flexbox, hover transitions, and the Titillium Web Google font |
| **Basit Yemek Sitesi** | A Turkish food website with a hero section, promotion/menu/featured sections, menu item cards, search box, and footer |
| **Basit Mimarlık Sitesi** | A minimal architecture site with an animated navbar underline hover effect and a serif typographic style |

Each project is a standalone folder with its own `index.html`, `style.css`, and `img/` directory.

## Skills Practiced

- Semantic HTML5 (`header`, `nav`, `section`, `footer`)
- CSS layout with Flexbox, hover effects, and transitions
- Bootstrap grid, components, and utility classes
- Google Fonts and Font Awesome icons
- Organizing a small multi-page static site

## Running Locally

No build step or dependencies needed. Clone the repo and open any `.html` file in a browser:

```bash
git clone https://github.com/ilhanumut01/Frontend_Learning.git
cd Frontend_Learning
# e.g. open "Car website/index.html" in your browser
```

Internet access is needed for Google Fonts and the Font Awesome CDN.
